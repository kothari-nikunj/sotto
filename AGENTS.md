# Agent setup entrypoint

When a user asks to install or configure Sotto from this repository, read
[`docs/AGENT-ONBOARDING.md`](docs/AGENT-ONBOARDING.md) first and follow its self-host or invited-Cloud
branch. Treat credentials, cloud account selection, Google consent, macOS source grants, and provider
purchase approval as user-owned steps. Do not send messages or launch a standalone general-purpose
Hermes gateway as a probe; the supported Sotto runtime includes the gateway it needs. Report only
checks you actually observed, and preserve the protected setup state for resume.

For installation tasks, follow only the selected user path and the checks in that guide; do not
assume a hosted operator workflow is available to end users.
