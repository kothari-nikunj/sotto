The flywheel, honestly

A self-improving system is a set of circuits. Some are closed — the output really does re-enter as input, and you can name the file where it happens. Some are plans. None today is merely recording — a ledger written for a consumer that hasn't shipped was deleted rather than badged, because data with no reader is a promise, not a kept promise. What a badge means

The temptation with a flywheel diagram is to draw every arrow solid. These three badges exist so the drawing can't lie.

The three badgesand their evidence bar
CLOSED Every station is shipped code, and the last one feeds the first. To earn this badge a loop must name the writer, the store, the reader, and the surface where the effect shows up — all four, all at HEAD. 4 named files
RECORDING The write side is live and accruing ahead of its consumer, with the arc back drawn dashed and dark because nothing reads it yet. No loop carries it today: the one that did — an offered-drafts ledger — was deleted rather than kept warm for a matcher that hasn't shipped. none at HEAD
PLANNED Designed, sequenced, not built. Shown because leaving it off the map would make the map look better than the machine. not built
